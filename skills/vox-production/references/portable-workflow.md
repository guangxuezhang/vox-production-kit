# Portable workflow

The three keys are runtime configuration, not repository content. Doubao is used for narration, the external image channel for clean backgrounds and 3–5 element transparent collections, and IMA only when the current episode source calls for it.

The package is intentionally deterministic after assets exist. Image generation remains provider-dependent; preserve the approved reference style and validate alpha edges before motion work. Do not ship API keys, tokens, or generated media in Git.

For GitHub delivery, create or select a repository, add this folder as the repository root, commit the package, and tag a release. Consumers clone the repository, run setup, configure `.env`, and use the Skill with the bundled Remotion project.
